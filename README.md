# B3 Financial Analysis Agent

An artificial intelligence agent that answers questions based on a company's financial documents: an annual report (PDF) and a historical series of indicators (CSV). Developed for the Alura Agent Challenge and Oracle's One AI For Tech program. 

## Description

The agent combines semantic search (RAG) over the PDF report content with structured queries on the CSV indicators spreadsheet, automatically deciding which source to consult based on the type of question. Questions that fall outside the agent's scope or cannot be answered using the documents are handled via fallback messages, preventing fabricated answers.
